# 日志方案

所有流程都必须写日志，用来事后排查问题。用户在「设置 > 数据 > 导出日志」一键打包分享。

## 写在哪里

- 文件：应用私有目录 `files/logs/YYYY-MM-DD.log`，每天一个文件。
- 同时输出到 logcat（tag `ArtemisAgent`），开发时用 `adb logcat -s ArtemisAgent` 看。
- 保留 7 天；单天最多 5 MB（超出后只记警告和错误）；总共最多 20 MB，超出先删最早的。
- 写文件在后台线程，不阻塞调用方；崩溃时同步写完再退出。

## 格式

```
2026-11-17 09:45:52.377 I call     [artemis-voice] you stopped, 14 chars recognized in 126 ms
日期       时间         级别 区域    [线程]          内容
```

级别：`I` 信息、`W` 警告（出了问题但能继续）、`E` 错误（带堆栈）。

## 区域

| 区域 | 内容 |
|---|---|
| `app` | 启动（版本、机型、系统）、崩溃、日志导出 |
| `agent` | 任务开始和结束（状态、步数、耗时、tokens）、每一步（耗时、动作名）、确认和提问、无障碍服务的连接和断开、复盘 |
| `model` | 模型请求的 HTTP 错误、重试 |
| `voice` | 语音服务的启动和停止、唤醒模型加载、唤醒、唤醒词更换、离线语音流程 |
| `call` | 语音通话：接通、声音设备、每一轮的时间点、工具调用、任务排队和合并、停止、挂断、服务器错误 |
| `mcp` | MCP 服务的启动、停止、请求 |
| `usage` | 用量上限触发 |
| `settings` | 每项设置的修改、模型服务的增删改、所选模型 |

## 隐私规则（强制）

**不能写进日志：**你说的话、输入的任务、屏幕上的文字、模型的回答、API Key、服务地址。只记录状态、耗时、数量、长度、名称和 ID。

`AppLog` 在写入前还会自动遮盖（兜底，不能代替上面的规则）：
- `Bearer …`、`sk-…` 这类密钥，`api_key=…`、`token: …`
- 所有 `http(s)://`、`ws(s)://` 地址
- 邮箱、大陆手机号、15～19 位的卡号或证件号

## 导出内容

`artemis-logs-时间.zip`：
- `logs/*.log`：最近 7 天的日志
- `info.txt`：版本、机型、系统、设置项（不含密钥）、声纹有没有录入、无障碍是否开启、模型服务（只有名称和数量，没有地址和 Key）、今天的用量
- `runs.txt`：最近 50 个任务的 ID、状态、步数、耗时、tokens、模型（不含任务内容和回答）

## 新代码的要求

- 用 `AppLog.i/w/e(AppLog.区域, "…")`，不要直接用 `android.util.Log`。
- 每个流程至少记录：开始、结束（结果和耗时）、每个失败分支（`w` 或 `e`，带原因）、用户的决定（选了第几项，不记内容）。
- `catch` 里不能什么都不记。
